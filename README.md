# Plume

A calm Markdown reader you can also edit in.

[Download the latest release](https://github.com/AbdurehmanSaleemi/plume-releases/releases/latest)

- **macOS:** choose the universal `.dmg` for Apple Silicon and Intel Macs. Quit Plume, open the DMG, drag Plume into Applications, and replace the previous copy.
- **Windows:** choose the `x64-setup.exe` installer and run it. The installer can install WebView2 if needed.

## Automatic updates

Install version 1.13 or newer once to enable automatic updates. Older versions need this first update installed manually.

Plume checks after launch and periodically while open. It downloads and verifies updates, saves your open documents, and restarts when you are idle. Save conflicts postpone installation. You can also check manually in **Settings → About**.

After an update, **What's new** shows the release notes inside Plume. The notes remain available in Settings → About and work offline.

Updates carry a cryptographic signature verified by Plume. The initial installers are not Apple-notarized or Windows Authenticode-signed, so your operating system may show a trust warning.

This repository contains official installers and release notes. Application source is maintained privately.
